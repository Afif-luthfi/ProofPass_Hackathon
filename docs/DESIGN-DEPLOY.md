# Local deployment utility

User direction: apply Anti Slop during implementation; use a simple tool interface first.

Design read: local wallet diagnosis and deployment tool for a first-time hackathon builder; a compact inspection sheet with readable labels. ENERGY 1 / RHYTHM 1 / MOTION 1.

This is a functional developer utility, not the final ProofPass product design.

- Single column: wallet inspection must come before network changes and deployment.
- Off-white surface and dark ink: a readable inspection sheet for long addresses and explanations.
- Dark green accent on primary actions: separate wallet connection/deployment from read-only secondary actions.
- Native system sans-serif: matches the operating system and needs no font download. Monospace is limited to addresses and hashes for comparison.
- Flat ruled sections: reflect wallet/network/contract/receipt sequence rather than marketing cards.
- Small button corners and square sections: distinguish actions from records.
- No illustrations, invented logo, marketing claims, or animation. Product name is plain text.
- Light and dark themes use the same structure and explicit focus outlines.
- Indonesian instructions serve the current user; the eventual public product can follow the PRD's English-language requirement.
